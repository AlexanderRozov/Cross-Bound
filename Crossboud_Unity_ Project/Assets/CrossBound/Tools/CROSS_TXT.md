# Работа с базой слов cross.txt

Файл `Assets/CrossBound/words/cross.txt` — словарь из **155 133 статей** в кодировке
windows-1251, по одной на строку:

```
СЛОВО - определение
ЁД - Река в Республике Коми, левый приток реки Большая Лоптюга
```

После фильтрации (только кириллица без дефисов/пробелов, длина 3–11, без дубликатов)
остаётся ~**86 700** пригодных для кроссвордов слов — с готовыми определениями
(они автоматически становятся текстом вопросов).

## Что уже работает (меню CrossBound → Crossword Generator)

1. **Источник «cross.txt»**: кнопка *Load / reload base* парсит файл
   (`Editor/CrosswordGenerator/CrosswordDictionarySource.cs`, встроенный cp1251-декодер,
   регистрация провайдера кодировок не нужна).
2. **Пул генерации**: задаётся размер (по умолчанию 600) и seed — детерминированная
   выборка из базы. Сортировка слов по «связности» (длина × частотность букв) делает
   генерацию быстрой: 12 слов на сетке 15×15 собираются за доли секунды.
3. **Валидация перед сохранением**: результат прогоняется через рантайм-валидатор
   (`CrosswordDataValidator`) — конфликты пересечений не попадут в игру.
4. **Два формата сохранения**:
   - `Resources` — JSON сразу playable, грузится через `Resources.Load` без настройки;
   - `Content/Crosswords` — под Addressables (нужно назначить адрес = id кроссворда).

## Наметка дальнейшей работы с базой

1. **Курируемые подборки.** Сейчас выборка случайная. Следующий шаг — экспорт
   тематических срезов: слова по префиксу/подстроке («КОСМОС», имена, города) или
   по длине. В генераторе это поле «Filter contains» + сохранение среза как JSON-словаря
   (режим Dictionary JSON), чтобы уровни были воспроизводимы.
2. **Качество определений.** Часть определений в базе — энциклопедические простыни
   и диалектные пометы `(разг.)`, `(уст.)`. Стоит добавить чистку: обрезка до
   первого предложения, максимальная длина (~120 символов), фильтр помет.
3. **Ё/Е.** Алфавит содержит Ё, но многие слова с Е не пересекаются со словами на Ё.
   Варианты: нормализация Ё→Е при генерации (опция окна) либо двойной индекс.
4. **Сложность уровней.** Частота букв уже считается в `CrosswordAnalysis`. Из неё
   можно выводить «скорость» слова и собирать уровни от простого (частотные слова)
   к сложному (редкие).
5. **Множество уровней в игре.** Рантайм уже умеет грузить любой `TextAsset`:
   доработка — список уровней в профиле игрока и экран выбора
   (id → файл из Resources/Addressables).
6. **Редактор определений.** Викторины с 155k вопросов не редактируются вручную,
   но для курируемых словарей (п. 1) полезен sub-asset `CrosswordDataSO`-редактор:
   правка вопроса → перегенерация JSON одной кнопкой.
